# ExpenseFlow – Visual Showcase & Screenshots

This folder contains the visual UI architecture, design specifications, and reference screenshots for **ExpenseFlow – Personal Finance Manager**.

## Screenshots Included

1. **01-dashboard-dark.png**
   - Main Dashboard view in Deep Navy dark SaaS theme.
   - Shows Total Balance, Monthly Income, Monthly Expense, Savings Rate, 6-Month Cashflow Area Chart, Category Breakdown Donut Chart, Recent Transactions, and Budget Health glance.

2. **02-transactions-ledger.png**
   - Transactions view with instant search, multi-faceted filters (Type, Category, Payment Method, Timeframe, Sort Order).
   - Shows summary pill of filtered items and pagination.

3. **03-transaction-add-modal.png**
   - Add/Edit Transaction dialog with Type toggle (Expense vs Income), amount validation in active currency (₹), category picker, payment methods, and notes.

4. **04-budgets-warnings.png**
   - Monthly category budgets view showing overall utilization progress bar, safe-to-spend indicator, 80% caution warnings, and exceeded status banners.

5. **05-analytics-reports.png**
   - Detailed financial analytics with interactive Timeframe selector (This Month, Last 3M, Last 6M, This Year, All Time).
   - Side-by-side Monthly Income vs Expense Bar Chart, Donut Share, Payment Channel analysis, and Category Breakdown Table.

6. **06-settings-management.png**
   - Profile management, Base Currency selector (INR ₹, USD $, EUR €, etc.), Dark/Light theme toggle, CSV Export, JSON Backup/Restore, and Data Reset controls.

7. **07-mobile-responsive-view.png**
   - Mobile smartphone view (iOS & Android compatible).
   - Demonstrates bottom navigation bar, touch-friendly buttons, adaptive cards without horizontal scrolling, and fluid responsive charts.
